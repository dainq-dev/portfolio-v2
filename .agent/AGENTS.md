# Agent Guidelines & Context for Portfolio Parallax

Welcome to the AI Agent workspace for the **Portfolio Parallax** project. This project heavily focuses on **3D animations and interactive web experiences** using **Three.js** and **GSAP**. 

To help you perform at your best, this directory (`.agent`) contains curated **Skills** and **Workflows** that you should leverage when working on tasks.

## 🗂️ Directory Structure

- **`.agent/skills/`** — Domain-specific knowledge, APIs, and best practices.
- **`.agent/workflow/`** — Standardized processes for reasoning, problem-solving, and brainstorming.

## 🔄 Workflows

Workflows dictate *how* you should approach problems and tasks in this repository. Please adhere to these guidelines to minimize mistakes and maximize output quality.

### 2. Brainstorming

## 📝 General Rules for AI Agents

1. **Check your context:** Always read the relevant `SKILL.md` files before starting a task related to Three.js, GSAP, or Parallax scrolling.
2. **Apply the "Way of Reasoning":** Follow the workflow for all tasks. Think before coding, prioritize simplicity, make surgical changes, and define success criteria.
3. **Use the Brainstorming workflow:** If the user asks for ideas, architectural design, or solutions to complex ambiguous problems, facilitate a structured brainstorming session.
